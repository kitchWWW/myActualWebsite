Patience is Understanding

2025
solo / improv base

on bandcamp.

A meditation on the nature of tension, damage, and uncertain futures.

This sound collage features some field recordings taken around Brooklyn, as well as "shuffled" drones, a technique I've become quite fond of that utilizes a bit of python code to chop up and shuffle a long audio file to create a slightly hectic interweaving result. A lot of the work of production for me then comes to transforming this chaotic force into a intentional experience.
